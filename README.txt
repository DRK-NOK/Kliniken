RDNOK Klinikfinder — Veröffentlichung:
1. Erstelle auf github.com ein öffentliches Repository rdnok-klinikfinder.
2. Lade index.html und kliniken.csv im Hauptverzeichnis hoch.
3. Settings > Pages > Deploy from branch > main > /(root) > Save.
4. Öffne https://BENUTZERNAME.github.io/rdnok-klinikfinder/ und prüfe die Karte und Google-Daten.
5. GitHub Pages funktioniert über HTTPS. Erst dadurch ist ein sinnvoller Test von OSM-Kartenkacheln und Google CSV möglich.
Hinweis: Spätere Fachbereichsänderungen direkt im veröffentlichten Google Sheet; mögliche Verzögerung der Veröffentlichung.
Vor Verwendung im Rettungsdienst medizinische Angaben prüfen.
